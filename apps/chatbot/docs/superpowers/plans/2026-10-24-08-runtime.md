# Piano 08 — Persistenza delle conversazioni e runtime del worker

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Far girare le interviste su Postgres: modelli Prisma delle conversazioni, store, coda
pg-boss e worker. Un messaggio in entrata (già normalizzato) diventa un turno: lock per
contatto, attesa breve della raffica, `nlu`, `engine`, risoluzione dei testi, **una transazione**
che salva stato, profilo, consensi, tracce, messaggi in uscita e job; poi `send-messages` li
spedisce **in ordine** su un canale. Tutto è testato con un canale finto e senza LLM reale.

**Architecture:** Gli store (`src/store/`) sono l'unico codice con le query Prisma. Il runtime
(`src/runtime/`) orchestra: `receive.ts` (ingresso, condiviso con il processo web del piano 09),
`process-contact.ts`, `apply-effects.ts` (un effetto del motore alla volta), `send-messages.ts`,
`worker.ts`. L'accodamento (`src/store/queue.ts`, su pg-boss) avviene **nella stessa
transazione** Prisma del turno, così un job esiste se e solo se il turno è stato salvato. Il
canale è un'interfaccia (`src/channels/channel.ts`): qui c'è solo l'implementazione finta; la
Cloud API di Meta arriva nel piano 09.

**Tech Stack:** TypeScript strict, Prisma 7 (adapter `pg`), `pg-boss` (nuova dipendenza), Zod 4,
pino, Vitest 4 (unit e integration), Postgres 16 in Docker. Nessun LLM reale nei test.

**Spec:** §4.1–4.2, §7.1–7.3 (effetti), §10.2–10.6 (modello dati, code, conservazione), §11.2–11.4
(percorso di un messaggio), §13 (errori), §14 (integrazione), §16 (ambienti), D24, D31, D45, D49, D57,
D77, D85, D87, D89, e le note sul piano 08 della roadmap.

## Decisioni prese in questo piano (da riportare nella spec, §2, come D102–D111)

Il piano 06 ha preso D80–D91, il 07 D92–D101.

- **D102 — Un turno, una transazione.** `process-contact` apre **una transazione interattiva**
  Prisma che comincia con `pg_advisory_xact_lock` sul contatto e finisce con il commit: lettura
  della raffica, NLU (con scadenza), `step()`, risoluzione dei testi, tutte le scritture e i
  job. Il lock regge per tutta la durata, quindi due worker non elaborano mai lo stesso contatto
  insieme; un crash annulla tutto e i messaggi restano `received`. Il timeout della transazione
  deriva dalle scadenze (`2 × TURN_NLU_DEADLINE_MS + 30 s`). Cache delle traduzioni e tracce di
  traduzione scrivono su un'altra connessione (nessuna chiave esterna verso il turno).
- **D103 — Accodamento transazionale.** I job pg-boss si inseriscono con l'opzione `db` di
  `send()` (un adattatore `executeSql` sopra la transazione Prisma). Se la transazione si
  annulla, il job non esiste. Il Task 8 lo dimostra con un test; se la combinazione non
  funzionasse con la versione installata, il ripiego è una tabella `Outbox` letta da un relay
  (non previsto in questo piano).
- **D104 — Stato persistito.** `Session.engineState` contiene lo stato del motore **senza
  `profile`**: il profilo vive in `CandidateProfile` (`standard`, `custom`, `fieldMeta`) e viene
  idratato prima di `step()` (D31). Un solo `session_started` per sessione: lo emette il runtime
  nella stessa transazione che crea la sessione. Se lo stato salvato non si legge più, il turno
  risponde con l'errore generico e porta la sessione a `needs_attention`.
- **D105 — Instradamento v1 (chiude D89).**
  - Senza sessione aperta, il primo messaggio crea la sessione sulla campagna con la parola
    chiave **uguale** al messaggio (trim e minuscolo, come il controllo delle collisioni, D63),
    altrimenti sulla campagna di default del numero; se non c'è, il turno vale `no_campaign` e non
    risponde (motivo registrato).
  - Quel messaggio **non viene interpretato**: la sessione parte con il benvenuto. Non si propone
    la lingua dal primo messaggio (§5.6 punto 3): resta fuori dalla v1.
  - Una sessione `completed` continua a ricevere i messaggi (fase dopo il completamento); solo
    una parola chiave di campagna ne apre una nuova.
  - "Aperta" = `openKey` valorizzata (`<contatto>:<numero>`, univoca): è la garanzia di una sola
    sessione aperta per contatto e numero. Si azzera con `StopSession` o con la fase `closed`.
  - Un messaggio in entrata da un contatto che aveva fatto opt-out lo riporta a `opted_in`
    (fonte `inbound`): il testo di sistema promette che può riscrivere quando vuole.
- **D106 — Raffica e attesa breve.** Il job `process-contact` è idempotente. Se l'ultimo messaggio
  ricevuto ha meno di `DEBOUNCE_MS` (3000) e il primo meno di `DEBOUNCE_MAX_WAIT_MS` (10000), il
  job si riprogramma (`startAfter`) senza fare nulla. I job doppi non danneggiano: il secondo
  trova i messaggi già elaborati.
- **D107 — NLU nel turno (note della roadmap).**
  - Scadenza `TURN_NLU_DEADLINE_MS` (20000): oltre, `interpretation: null`.
  - Un'eccezione dell'interprete vale `null`.
  - Un'eccezione di `step()` che non sia `EngineError` diventa errore generico + `FlagSession`
    `incoherent_state` con stato invariato.
  - La storia per l'NLU è la copia redatta (`Message.bodyRedacted`, calcolata con
    `redactWithEvidence`) degli ultimi N messaggi del candidato: l'originale non rientra mai nel
    contesto.
  - I messaggi non testuali non fanno girare il motore (turno `ignored_media`): la risposta "per ora
    scrivimi in testo" è del piano 09.
- **D108 — Invio.** `Message` in stato `queued` è l'outbox. `send-messages` prende i messaggi di
  un contatto e di un numero **in ordine** (`ordinal`) con un'assegnazione protetta da lock e da una
  scadenza (`SEND_LEASE_MS`), così due job non si scavalcano. L'invio è *almeno una volta*.
  Errore temporaneo: il messaggio torna `queued`, il job si rilancia con attesa crescente; dopo
  `SEND_MAX_ATTEMPTS` (5) diventa definitivo. Errore definitivo: `failed`, i messaggi successivi
  dello stesso turno `failed` (`skipped_after_failure`), evento `outbound_failed` al motore.
- **D109 — Dati alla chiusura.** `StopSession` con `dataPolicy: delete` cancella subito profilo,
  modifiche, corpi dei messaggi (tranne quelli in uscita ancora da inviare) e tracce della
  sessione. Il job `delete-contact` viene solo accodato: il gestore è del piano 11. `Consent`
  sopravvive alla cancellazione del contatto (`contactId` e `sessionId` diventano `NULL`) con
  `contactHash`, la prova minima di §10.6.
- **D110 — Tracce e cache su database.** `NluTrace` si scrive nella transazione del turno (il
  turno ha un id scelto in anticipo); `input` è salvato solo sulla prima chiamata di ogni catena
  (primaria e correzione), non su ritentativi e riserva, che mandano gli stessi messaggi. La
  scadenza di conservazione è del piano 11. `TranslationCache` è una tabella con chiave
  (`sourceHash`, `language`).
- **D111 — Modelli rinviati e aggiunti.** `CvDocument` arriva con il piano 10 e
  `InboundDeadLetter` con il 09 (i primi che li usano); `Session.origin` resta fuori finché non
  esiste il contatto proattivo. Si aggiunge `SessionFlag` (motivo, campo, `needsAttention`): è dove
  `FlagSession` lascia traccia; l'avviso vero è del piano 11 (per ora un log `warn` con gli id).

**Correzioni dopo la revisione dei Task 1–7 (spec D111a–D111e, già nel registro).** I frammenti
dei task successivi sono stati scritti prima e vanno adattati: `insertTurn` vuole `contactId`;

- [ ] **Step 4: Implementare `src/runtime/config.ts`**

```ts
import { z } from "zod";

const Ms = z.coerce.number().int().min(0);

const RuntimeEnvSchema = z.object({
  /** Quiet time before a burst of messages becomes one turn (spec §11.2, D106). */
  DEBOUNCE_MS: Ms.default(3000),
  /** A burst is never held longer than this. */
  DEBOUNCE_MAX_WAIT_MS: Ms.default(10_000),
  /** Past this the NLU counts as unavailable for the turn (D107). */
  TURN_NLU_DEADLINE_MS: z.coerce.number().int().positive().default(20_000),
  SEND_LEASE_MS: z.coerce.number().int().positive().default(60_000),
  SEND_MAX_ATTEMPTS: z.coerce.number().int().positive().default(5),
  WORKER_BATCH_SIZE: z.coerce.number().int().positive().max(20).default(4),
  /** Becomes part of SQL identifiers: letters, digits and underscores only. */
  QUEUE_SCHEMA: z
    .string()
    .regex(/^[a-z][a-z0-9_]*$/, "lowercase letters, digits and underscores")
    .default("bot_queue"),
});

export interface RuntimeConfig {
  readonly debounceMs: number;
  readonly debounceMaxWaitMs: number;
  readonly nluDeadlineMs: number;
  /** Timeout of the turn transaction (D102): the NLU and the translations both wait inside it. */
  readonly turnTransactionMs: number;
  readonly sendLeaseMs: number;
  readonly sendMaxAttempts: number;
  readonly workerBatchSize: number;
  readonly queueSchema: string;
}

/** Same convention as the NLU configuration: `KEY=` means unset; no values in the messages. */
export function parseRuntimeConfig(
  source: Readonly<Record<string, string | undefined>>,
): RuntimeConfig {
  const present = Object.fromEntries(
    Object.entries(source).filter(([, value]) => value !== undefined && value.trim() !== ""),
  );
  const result = RuntimeEnvSchema.safeParse(present);
  if (!result.success) {
    const details = result.error.issues
      .map((issue) => `${issue.path.join(".")}: ${issue.message}`)
      .join("; ");
    throw new Error(`Invalid runtime configuration: ${details}`);
  }
  const env = result.data;
  return {
    debounceMs: env.DEBOUNCE_MS,
    debounceMaxWaitMs: env.DEBOUNCE_MAX_WAIT_MS,
    nluDeadlineMs: env.TURN_NLU_DEADLINE_MS,
    turnTransactionMs: 2 * env.TURN_NLU_DEADLINE_MS + 30_000,
    sendLeaseMs: env.SEND_LEASE_MS,
    sendMaxAttempts: env.SEND_MAX_ATTEMPTS,
    workerBatchSize: env.WORKER_BATCH_SIZE,
    queueSchema: env.QUEUE_SCHEMA,
  };
}
```

```ts
import { z } from "zod";
import type { FieldStatus, ProfileSnapshot } from "../engine/profile-snapshot";
import { CUSTOM_FIELD_PREFIX } from "../profile/custom-fields";

export type ChangeSourceName = "extraction" | "edit" | "system";

export interface FieldMeta {
  readonly confidence: number;
  readonly status: FieldStatus;
  /** The source of the last update. */
  readonly source: ChangeSourceName;
}

/** The three JSON columns of CandidateProfile (spec §10.3). */
export interface StoredProfile {
  /** Standard fields by key, values only. */
  readonly standard: Readonly<Record<string, unknown>>;
  /** Custom fields by key without the `custom.` prefix. */
  readonly custom: Readonly<Record<string, unknown>>;
  /** By full field reference ("firstName", "custom.x"). */
  readonly fieldMeta: Readonly<Record<string, FieldMeta>>;
}

export const EMPTY_PROFILE: StoredProfile = { standard: {}, custom: {}, fieldMeta: {} };

const MetaSchema = z.strictObject({
  confidence: z.number().min(0).max(1),
  status: z.enum(["confirmed", "inferred", "unresolved"]),
  source: z.enum(["extraction", "edit", "system"]),
});

const StoredProfileSchema = z.strictObject({
  standard: z.record(z.string(), z.unknown()),
  custom: z.record(z.string(), z.unknown()),
  fieldMeta: z.record(z.string(), MetaSchema),
});

/** What comes out of the database is a boundary: it is parsed, not trusted. */
export function parseStoredProfile(json: {
  standard: unknown;
  custom: unknown;
  fieldMeta: unknown;
}): StoredProfile {
  const result = StoredProfileSchema.safeParse(json);
  if (!result.success) throw new Error("the stored profile cannot be read");
  return result.data;
}

function split(ref: string): { bucket: "standard" | "custom"; key: string } {
  return ref.startsWith(CUSTOM_FIELD_PREFIX)
    ? { bucket: "custom", key: ref.slice(CUSTOM_FIELD_PREFIX.length) }
    : { bucket: "standard", key: ref };
}

/** Pure: returns a new profile. An unresolved field keeps its meta but no value. */
export function setStoredField(
  profile: StoredProfile,
  ref: string,
  value: unknown,
  meta: FieldMeta,
): StoredProfile {
  const { bucket, key } = split(ref);
  const values = { ...profile[bucket] };
  if (meta.status === "unresolved") delete values[key];
  else values[key] = value;
  return { ...profile, [bucket]: values, fieldMeta: { ...profile.fieldMeta, [ref]: meta } };
}

export function storedValue(profile: StoredProfile, ref: string): unknown {
  const { bucket, key } = split(ref);
  return Object.hasOwn(profile[bucket], key) ? profile[bucket][key] : undefined;
}

/** D31: the engine's flat snapshot, rebuilt from the profile row. */
export function toSnapshot(profile: StoredProfile): ProfileSnapshot {
  return Object.fromEntries(
    Object.entries(profile.fieldMeta).map(([ref, meta]) => [
      ref,
      {
        value: meta.status === "unresolved" ? null : (storedValue(profile, ref) ?? null),
        confidence: meta.confidence,
        status: meta.status,
      },
    ]),
  );
}
```

```ts
import { z } from "zod";
import type { ProfileSnapshot } from "../engine/profile-snapshot";
import type { PendingConfirmation, SessionState } from "../engine/state";
import { LanguageCodeSchema } from "../i18n/localized-text";

const PendingSchema = z.discriminatedUnion("kind", [
  z.strictObject({
    kind: z.literal("value"),
    field: z.string(),
    value: z.unknown(),
    confidence: z.number(),
  }),
  z.strictObject({
    kind: z.literal("edit"),
    field: z.string(),
    oldValue: z.unknown(),
    newValue: z.unknown(),
  }),
  z.strictObject({ kind: z.literal("delete_data") }),
]);

/** SessionState without `profile` (D104). */
const PersistedStateSchema = z.strictObject({
  phase: z.enum(["language", "flow", "post_completion", "closed"]),
  stepId: z.string().nullable(),
  questionId: z.string().nullable(),
  clarifications: z.number().int().min(0),
  pendingConfirmation: PendingSchema.nullable(),
  outcomes: z.record(z.string(), z.string()),
  language: LanguageCodeSchema.nullable(),
  consentsAccepted: z.boolean(),
});
export type PersistedState = z.infer<typeof PersistedStateSchema>;

function pending(p: z.infer<typeof PendingSchema> | null): PendingConfirmation | null {
  if (p === null) return null;
  switch (p.kind) {
    case "value":
      return { kind: "value", field: p.field, value: p.value, confidence: p.confidence };
    case "edit":
      return { kind: "edit", field: p.field, oldValue: p.oldValue, newValue: p.newValue };
    case "delete_data":
      return { kind: "delete_data" };
  }
}

/** The profile is CandidateProfile's job: it never goes into engineState (D104). */
export function encodeState(state: SessionState): PersistedState {
  const { profile: _profile, ...rest } = state;
  return rest;
}

export function decodeState(json: unknown, profile: ProfileSnapshot): SessionState {
  const result = PersistedStateSchema.safeParse(json);
  if (!result.success) throw new Error("the stored engine state cannot be read");
  const state = result.data;
  return { ...state, pendingConfirmation: pending(state.pendingConfirmation), profile };
}
```

```ts
export async function setPreferredLanguage(
  tx: Tx,
  contactId: string,
  language: string,

  await tx.contact.update({ where: { id: contactId }, data: { preferredLanguage: language } });

export interface InboundSeen {
  readonly contactId: string;
  readonly senderNumberId: string;
  readonly at: Date;
}

/**
 * An inbound message opens the 24 hour window (spec §11.3) and brings an opted-out contact
 * back (D105): the closing text promises they can write again whenever they want.

export async function registerInbound(tx: Tx, input: InboundSeen): Promise<void> {

    contactId_senderNumberId: { contactId: input.contactId, senderNumberId: input.senderNumberId },
  };
  await tx.contactChannelState.upsert({
    where,
    create: {
      contactId: input.contactId,
      senderNumberId: input.senderNumberId,
      lastInboundAt: input.at,
      optInSource: "inbound",
      optInAt: input.at,
    },
    update: { lastInboundAt: input.at },
  });
  await tx.contactChannelState.updateMany({
    where: { contactId: input.contactId, senderNumberId: input.senderNumberId, optInStatus: "opted_out" },
    data: { optInStatus: "opted_in", optInSource: "inbound", optInAt: input.at },
  });
}

    where: { contactId_senderNumberId: { contactId, senderNumberId } },
    create: { contactId, senderNumberId, optInStatus: "opted_out", optOutAt: at },
    update: { optInStatus: "opted_out", optOutAt: at },
```

```ts
import type { Database, Tx } from "./db";
import { lockKey } from "./db";

export type MessageKind = "text" | "audio" | "image" | "document" | "location" | "unsupported";

/** The provider's raw payload, as JSON. Exported so the runtime never imports Prisma types. */
export type PayloadRaw = Prisma.InputJsonValue;

export interface InboundMessageInput {
  readonly contactId: string;
  readonly senderNumberId: string;
  readonly providerMessageId: string;
  readonly type: MessageKind;
  readonly body: string | null;
  readonly payloadRaw: PayloadRaw;
}

/** `ON CONFLICT DO NOTHING` on the provider id: a duplicate neither fails nor aborts the transaction. */
export async function insertInboundMessage(
  tx: Tx,
  input: InboundMessageInput,
): Promise<{ created: boolean }> {
  const result = await tx.message.createMany({
    data: [{ ...input, direction: "inbound", status: "received" }],
    skipDuplicates: true,
  });
  return { created: result.count === 1 };
}

export interface BurstMessage {
  readonly id: string;
  readonly type: MessageKind;
  readonly body: string | null;
  readonly createdAt: Date;
}

/** The unprocessed inbound messages of a contact on a number, oldest first (spec §11.2). */
export function receivedBurst(
  tx: Tx,
  contactId: string,
  senderNumberId: string,

  return tx.message.findMany({
    where: { contactId, senderNumberId, direction: "inbound", status: "received" },
    orderBy: { ordinal: "asc" },
    select: { id: true, type: true, body: true, createdAt: true },
  });

        turnId: m.turnId,
        bodyRedacted: m.bodyRedacted,
      },
    });
  }
}

/** The last `limit` redacted candidate messages of the session, oldest first (D107). */
export async function recentRedactedHistory(
  tx: Tx,
  sessionId: string,
  limit: number,
): Promise<string[]> {
  if (limit === 0) return [];
  const rows = await tx.message.findMany({
    where: { sessionId, direction: "inbound", type: "text", bodyRedacted: { not: null } },
    orderBy: { ordinal: "desc" },
    take: limit,
    select: { bodyRedacted: true },
  });
  return rows.reverse().flatMap((row) => (row.bodyRedacted === null ? [] : [row.bodyRedacted]));
}

export interface OutboundMessageInput {
  readonly contactId: string;
  readonly senderNumberId: string;
  readonly sessionId: string;
  readonly turnId: string | null;
  readonly body: string;
  readonly language: string;
  readonly stepId: string | null;
  readonly questionId: string | null;

/** One insert at a time: the sequence number must follow the engine's order. */
export async function queueOutbound(
  tx: Tx,
  messages: readonly OutboundMessageInput[],
): Promise<void> {
  for (const m of messages) {
    await tx.message.create({
      data: { ...m, direction: "outbound", type: "text", status: "queued" },
    });
  }

  readonly contactId: string;
  readonly senderNumberId: string;
}

export interface ClaimedMessage {
  readonly id: string;
  readonly contactId: string;
  readonly senderNumberId: string;
  readonly sessionId: string | null;
  readonly turnId: string | null;
  readonly body: string;
  readonly attempts: number;
}

/**
 * D108: the next queued message of a contact on a number, or "busy" when another sender holds
 * a live claim, or null when nothing is left. The advisory lock makes the check-and-claim atomic;
 * the lease frees a message whose sender crashed.
 */
export async function claimNextOutbound(
  db: Database,
  key: SendKey,
  now: Date,
  leaseMs: number,
): Promise<ClaimedMessage | "busy" | null> {
  return db.$transaction(async (tx) => {
    await lockKey(tx, `send:${key.contactId}:${key.senderNumberId}`);
    const where = { ...key, direction: "outbound" as const };
    await tx.message.updateMany({
      where: { ...where, status: "sending", leaseUntil: { lt: now } },
      data: { status: "queued", leaseUntil: null },
    });
    const live = await tx.message.count({ where: { ...where, status: "sending" } });
    if (live > 0) return "busy";
    const next = await tx.message.findFirst({
      where: { ...where, status: "queued" },
      orderBy: { ordinal: "asc" },
    });
    if (!next || next.body === null) return null;
    const claimed = await tx.message.update({
      where: { id: next.id },
      data: {
        status: "sending",
        attempts: { increment: 1 },
        leaseUntil: new Date(now.getTime() + leaseMs),
      },
    });
    return {
      id: claimed.id,
      contactId: claimed.contactId,
      senderNumberId: claimed.senderNumberId,
      sessionId: claimed.sessionId,
      turnId: claimed.turnId,
      body: next.body,
      attempts: claimed.attempts,
    };
  });
}

export type SendResult =
  | { readonly kind: "sent"; readonly providerMessageId: string; readonly at: Date }
  | { readonly kind: "transient"; readonly code: string }
  | { readonly kind: "permanent"; readonly code: string; readonly at: Date };

export async function finishSend(
  db: Database,
  message: ClaimedMessage,
  result: SendResult,
): Promise<void> {
  await db.$transaction(async (tx) => {
    switch (result.kind) {
      case "sent":
        await tx.message.update({
          where: { id: message.id },
          data: {
            status: "sent",
            providerMessageId: result.providerMessageId,
            sentAt: result.at,
            leaseUntil: null,
            errorCode: null,
          },
        });
        return;
      case "transient":
        await tx.message.update({
          where: { id: message.id },
          data: { status: "queued", leaseUntil: null, errorCode: result.code },
        });
        return;
      case "permanent":
        await tx.message.update({
          where: { id: message.id },
          data: { status: "failed", failedAt: result.at, leaseUntil: null, errorCode: result.code },
        });
        if (message.turnId !== null) {
          // Spec §11.3: the rest of the turn is not sent after a definitive error.
          await tx.message.updateMany({
            where: { turnId: message.turnId, direction: "outbound", status: "queued" },
            data: { status: "failed", failedAt: result.at, errorCode: "skipped_after_failure" },
          });
        }
        return;
    }
  });
}
```

```ts
import {
  parseStoredProfile,
  setStoredField,
  storedValue,
  type ChangeSourceName,
  type StoredProfile,
} from "../runtime/profile-codec";
import type { Tx } from "./db";

function toJson(value: unknown): Prisma.InputJsonValue | typeof Prisma.JsonNull {
  return value === null || value === undefined ? Prisma.JsonNull : (value as Prisma.InputJsonValue);
}

export async function loadProfile(tx: Tx, sessionId: string): Promise<StoredProfile> {
  const row = await tx.candidateProfile.findUniqueOrThrow({ where: { sessionId } });
  return parseStoredProfile(row);
}

export interface FieldUpdate {
  readonly field: string;
  readonly value: unknown;
  readonly confidence: number;
  readonly status: "confirmed" | "inferred";
}

/** One ProfileChange per field (CLAUDE.md), in the same transaction as the profile. */
export async function applyProfileFields(
  tx: Tx,
  sessionId: string,
  source: ChangeSourceName,
  turnId: string | null,
  fields: readonly FieldUpdate[],
): Promise<void> {
  const row = await tx.candidateProfile.findUniqueOrThrow({ where: { sessionId } });
  let profile = parseStoredProfile(row);
  for (const f of fields) {
    const oldValue = storedValue(profile, f.field);
    profile = setStoredField(profile, f.field, f.value, {
      confidence: f.confidence,
      status: f.status,
      source,
    });
    await tx.profileChange.create({
      data: {
        profileId: row.id,
        field: f.field,
        oldValue: toJson(oldValue),
        newValue: toJson(f.value),
        source,
        turnId,
        confidence: f.confidence,
      },
    });
  }
  await tx.candidateProfile.update({
    where: { id: row.id },
    data: { standard: profile.standard, custom: profile.custom, fieldMeta: profile.fieldMeta },
  });
}

/** The engine gave up on a required field: the value goes, the field stays known (spec §6). */
export async function markFieldUnresolved(
  tx: Tx,
  sessionId: string,
  field: string,
  turnId: string | null,
): Promise<void> {
  const row = await tx.candidateProfile.findUniqueOrThrow({ where: { sessionId } });
  const profile = parseStoredProfile(row);
  const next = setStoredField(profile, field, null, {
    confidence: 0,
    status: "unresolved",
    source: "system",
  });
  await tx.profileChange.create({
    data: {
      profileId: row.id,
      field,
      oldValue: toJson(storedValue(profile, field)),
      newValue: Prisma.JsonNull,
      source: "system",
      turnId,
    },
  });
  await tx.candidateProfile.update({
    where: { id: row.id },
    data: { standard: next.standard, custom: next.custom, fieldMeta: next.fieldMeta },
  });
}

  tx: Tx,
  sessionId: string,
  shared: boolean,

  await tx.candidateProfile.update({ where: { sessionId }, data: { sharedWithGlobal: shared } });
}

  await tx.candidateProfile.update({ where: { sessionId }, data: { completedAt: at } });
}

/**
 * D109, spec §10.6: `dataPolicy: delete`. The profile and what it was built from go; replies
 * still waiting to be sent stay (they are the goodbye). The Consent rows are not touched.
 */
export async function purgeSessionData(tx: Tx, sessionId: string): Promise<void> {
  await tx.profileChange.deleteMany({ where: { profile: { sessionId } } });
  await tx.candidateProfile.update({
    where: { sessionId },
    data: { standard: {}, custom: {}, fieldMeta: {}, sharedWithGlobal: false },
  });
  await tx.nluTrace.deleteMany({ where: { turn: { sessionId } } });
  await tx.message.updateMany({
    where: { sessionId, NOT: { direction: "outbound", status: { in: ["queued", "sending"] } } },
    data: { body: null, bodyRedacted: null, payloadRaw: Prisma.DbNull },
  });
  await tx.message.updateMany({
    where: { sessionId, direction: "outbound", status: { in: ["queued", "sending"] } },
    data: { bodyRedacted: null, payloadRaw: Prisma.DbNull },
  });
}
```

```ts
import type { CachedTranslation, TranslationCache } from "../i18n/translation-cache";
import type { LanguageCode } from "../i18n/localized-text";
import { Prisma } from "../generated/prisma/client";
import type { NluTraceRecord, NluTraceSink } from "../nlu/trace";
import type { Database, Tx } from "./db";

export interface TraceRow {
  readonly turnId: string | null;
  readonly task: string;
  readonly promptVersion: string;
  readonly provider: string;
  readonly model: string;
  readonly attempt: string;
  readonly repair: boolean;
  readonly input: Prisma.InputJsonValue | typeof Prisma.JsonNull;
  readonly output: string | null;
  readonly valid: boolean;
  readonly latencyMs: number;
  readonly inputTokens: number | null;
  readonly outputTokens: number | null;
  readonly costEstimate: number | null;
  readonly error: string | null;
  readonly createdAt: Date;
}

/**
 * D110: retries and the fallback send the same messages as the call that started the chain
 * (primary or repair), so only that one keeps its `input`.
 */
export function toTraceRows(records: readonly NluTraceRecord[]): TraceRow[] {
  return records.map((r) => ({
    turnId: r.turnId,
    task: r.task,
    promptVersion: r.promptVersion,
    provider: r.provider,
    model: r.model,
    attempt: r.attempt,
    repair: r.repair,
    input: r.attempt === "primary" ? (r.input as unknown as Prisma.InputJsonValue) : Prisma.JsonNull,
    output: r.output,
    valid: r.valid,
    latencyMs: Math.round(r.latencyMs),
    inputTokens: r.inputTokens,
    outputTokens: r.outputTokens,
    costEstimate: r.costEstimate,
    error: r.error,
    createdAt: new Date(r.at),
  }));
}

/** The turn's traces, written in its transaction (the turn row must exist already). */
export async function insertTraces(tx: Tx, records: readonly NluTraceRecord[]): Promise<void> {
  if (records.length === 0) return;
  await tx.nluTrace.createMany({ data: toTraceRows(records) });
}

/** For traces that belong to no turn (translations): written straight away. */
export function createDatabaseTraceSink(db: Database): NluTraceSink {
  return { write: (record) => insertTraces(db, [record]) };
}

export function createDatabaseTranslationCache(db: Database): TranslationCache {
  return {
    async get(sourceHash: string, language: LanguageCode): Promise<CachedTranslation | undefined> {
      const row = await db.translationCache.findUnique({
        where: { sourceHash_language: { sourceHash, language } },
      });
      return row
        ? { text: row.text, reviewed: row.reviewed, provider: row.provider, model: row.model }
        : undefined;
    },
    async set(sourceHash: string, language: LanguageCode, entry: CachedTranslation): Promise<void> {
      const data = { text: entry.text, reviewed: entry.reviewed, provider: entry.provider, model: entry.model };
      await db.translationCache.upsert({
        where: { sourceHash_language: { sourceHash, language } },
        create: { sourceHash, language, ...data },
        update: data,
      });
    },
  };
}
```

```ts
import { PgBoss } from "pg-boss";
import { z } from "zod";
import type { KubriEvent } from "../engine/effects";
import type { Tx } from "./db";

export const QUEUE_NAMES = [
  "process-contact",
  "send-messages",
  "kubri-webhook",
  "cv",
  "geocoding",
  "delete-contact",
] as const;
export type QueueName = (typeof QUEUE_NAMES)[number];

const KUBRI_EVENTS = [
  "consents.accepted",
  "block.completed",
  "interview.completed",
  "profile.updated",
] as const satisfies readonly KubriEvent[];

/** Zod at every boundary: a job payload is parsed when a handler receives it. */
const PAYLOAD_SCHEMAS = {
  "process-contact": z.strictObject({ contactId: z.string(), senderNumberId: z.string() }),
  "send-messages": z.strictObject({ contactId: z.string(), senderNumberId: z.string() }),
  "kubri-webhook": z.strictObject({ sessionId: z.string(), event: z.enum(KUBRI_EVENTS) }),
  cv: z.strictObject({ sessionId: z.string() }),
  geocoding: z.strictObject({ sessionId: z.string() }),
  "delete-contact": z.strictObject({ contactId: z.string() }),
} as const satisfies Record<QueueName, z.ZodType>;

export type JobPayloads = { [Q in QueueName]: z.infer<(typeof PAYLOAD_SCHEMAS)[Q]> };

export interface EnqueueOptions {
  /** Seconds before the job can run. */
  readonly startAfterSeconds?: number;
}

/** What the runtime needs to enqueue: easy to fake in unit tests. */
export interface JobQueue {
  /** With `tx`, the job exists only if that transaction commits (D103). */
  enqueue<Q extends QueueName>(
    name: Q,
    payload: JobPayloads[Q],
    options?: EnqueueOptions,
    tx?: Tx,
  ): Promise<void>;
}

export interface QueueSettings {
  /** Direct (5432) connection: pg-boss does not work behind the transaction pooler. */
  readonly connectionString: string;
  readonly schema: string;
  readonly retryLimit?: number;
  readonly retryDelaySeconds?: number;
}

export interface WorkOptions {
  readonly batchSize: number;
  /** pg-boss polls the queue; tests lower it to keep them fast (minimum 0.5). */
  readonly pollingIntervalSeconds?: number;
}

export interface QueueRuntime {
  readonly queue: JobQueue;
  start(): Promise<void>;
  stop(): Promise<void>;
  work<Q extends QueueName>(
    name: Q,
    handler: (payload: JobPayloads[Q]) => Promise<void>,
    options: WorkOptions,
  ): Promise<void>;
  /** Tests: empties every queue. */
  purge(): Promise<void>;
}

/** An executeSql adapter on a Prisma transaction: pg-boss writes through it (BYODB). */
function transactionAdapter(tx: Tx) {
  return {
    executeSql: async (text: string, values: unknown[] = []) => ({
      rows: await tx.$queryRawUnsafe<unknown[]>(text, ...values),
    }),
  };
}

const dead = (name: string): string => `${name}-dead`;

export function createQueueRuntime(settings: QueueSettings): QueueRuntime {
  const boss = new PgBoss({ connectionString: settings.connectionString, schema: settings.schema });
  boss.on("error", () => {
    // pg-boss reports connection problems here; the worker's own logging covers the effects.
  });

  const queue: JobQueue = {
    async enqueue(name, payload, options = {}, tx) {
      await boss.send(name, payload, {
        ...(options.startAfterSeconds === undefined ? {} : { startAfter: options.startAfterSeconds }),
        ...(tx ? { db: transactionAdapter(tx) } : {}),
      });
    },
  };

  return {
    queue,
    async start() {
      await boss.start();
      for (const name of QUEUE_NAMES) {
        // The dead letter queue must exist before the queue that points at it.
        await boss.createQueue(dead(name));
        await boss.createQueue(name, {
          deadLetter: dead(name),
          retryLimit: settings.retryLimit ?? 5,
          retryDelay: settings.retryDelaySeconds ?? 10,
          retryBackoff: true,
        });
      }
    },
    async stop() {
      await boss.stop({ graceful: true, timeout: 10_000 });
    },
    async work(name, handler, options) {
      await boss.work(
        name,
        {
          batchSize: options.batchSize,
          ...(options.pollingIntervalSeconds === undefined
            ? {}
            : { pollingIntervalSeconds: options.pollingIntervalSeconds }),
        },
        async (jobs) => {
          const results = await Promise.allSettled(
            jobs.map((job) =>
              handler(PAYLOAD_SCHEMAS[name].parse(job.data) as JobPayloads[typeof name]),
            ),
          );
          const failed = results.find((r) => r.status === "rejected");
          // One failing job fails the batch: handlers are idempotent, the others run again.
          if (failed) throw failed.reason;
        },
      );
    },
    async purge() {
      for (const name of QUEUE_NAMES) {
        await boss.deleteAllJobs(name);
        await boss.deleteAllJobs(dead(name));
      }
    },
  };
}
```

```ts
  readonly id: string;
  readonly slug: string;
  readonly provider: "meta" | "twilio";
  /** Identifiers and names of secrets, never credentials (spec §10.1). */
  readonly providerConfig: unknown;

export interface OutboundText {
  /** The id of our Message row: lets an adapter deduplicate if the provider supports it. */
  readonly clientMessageId: string;
  readonly sender: OutboundSender;
  readonly to: { readonly externalId: string; readonly phoneE164: string };
  readonly text: string;
}

export type SendOutcome =
  | { readonly ok: true; readonly providerMessageId: string }
  /** transient: worth retrying (limits, 5xx); permanent: stop the turn's other messages. */
  | { readonly ok: false; readonly kind: "transient" | "permanent"; readonly code: string };

/**
 * The only module that talks to a messaging provider (CLAUDE.md). Plan 09 implements Meta's
 * Cloud API behind it; here there are a fake and a console one.
 */
export interface ChannelAdapter {
  send(message: OutboundText): Promise<SendOutcome>;
}

/** For tests: a script of outcomes first (failures are not recorded), then success. */
export class FakeChannel implements ChannelAdapter {
  readonly sent: OutboundText[] = [];
  private readonly script: SendOutcome[];
  private crash: Error | null = null;

  constructor(script: readonly SendOutcome[] = []) {
    this.script = [...script];
  }

  /** The next send() throws, like an adapter with a broken socket. */
  throwOnNext(error: Error): void {
    this.crash = error;
  }

  send(message: OutboundText): Promise<SendOutcome> {
    if (this.crash) {
      const error = this.crash;
      this.crash = null;
      return Promise.reject(error);
    }
    const scripted = this.script.shift();
    if (scripted && !scripted.ok) return Promise.resolve(scripted);
    this.sent.push(message);
    return Promise.resolve({
      ok: true,
      providerMessageId: scripted?.ok ? scripted.providerMessageId : `fake-${this.sent.length}`,
    });
  }
}

/** For trying the worker by hand: the candidate's "phone" is the terminal. */
export class ConsoleChannel implements ChannelAdapter {
  private count = 0;

  constructor(private readonly write: (line: string) => void) {}

  send(message: OutboundText): Promise<SendOutcome> {
    this.count += 1;
    this.write(`→ ${message.to.phoneE164}: ${message.text}`);
    return Promise.resolve({ ok: true, providerMessageId: `console-${this.count}` });
  }
```

```ts
export type Deadline<T> = { readonly timedOut: false; readonly value: T } | { readonly timedOut: true };

/**
 * Gives up waiting after `ms`; the work itself cannot be cancelled and keeps running. Promise.race
 * subscribes to it, so a late failure is handled and never becomes an unhandled rejection.
 */
export async function withDeadline<T>(work: Promise<T>, ms: number): Promise<Deadline<T>> {
  let timer: NodeJS.Timeout | undefined;
  const timeout = new Promise<{ timedOut: true }>((resolve) => {
    timer = setTimeout(() => resolve({ timedOut: true }), ms);
  });
  try {
    return await Promise.race([
      work.then((value): Deadline<T> => ({ timedOut: false, value })),
      timeout,
    ]);
  } finally {
    clearTimeout(timer);
  }
}
```

```ts
import type { Logger } from "pino";
import type { CampaignDefinition } from "../campaigns/schema/campaign";
import type { Effect } from "../engine/effects";
import type { EngineEvent } from "../engine/events";
import type { Interpretation } from "../engine/interpretation";
import type { SessionState } from "../engine/state";
import { step } from "../engine/step";
import { systemText } from "../engine/turn";
import type { InterpretRequest, Interpreter } from "../nlu/interpreter";
import { withDeadline } from "./deadline";

export interface SafeInterpretation {
  /** null: unavailable, whatever the reason; the engine still answers (D32). */
  readonly interpretation: Interpretation | null;
  readonly problem: "timeout" | "error" | null;
}

const errorName = (error: unknown): string => (error instanceof Error ? error.name : "unknown");

/** D107: a slow or broken interpreter is an unavailable NLU, never a silent turn. */
export async function interpretSafely(
  interpreter: Interpreter,
  request: InterpretRequest,
  deadlineMs: number,
  logger: Logger,
): Promise<SafeInterpretation> {
  try {
    // The wrapper turns a synchronous throw into a rejection.
    const result = await withDeadline(
      Promise.resolve().then(() => interpreter.interpret(request)),
      deadlineMs,
    );
    if (result.timedOut) {
      logger.warn({ turnId: request.turnId, deadlineMs }, "nlu deadline exceeded");
      return { interpretation: null, problem: "timeout" };
    }
    return { interpretation: result.value, problem: null };
  } catch (error: unknown) {
    logger.warn({ turnId: request.turnId, error: errorName(error) }, "nlu failed");
    return { interpretation: null, problem: "error" };
  }
}

export interface SafeStep {
  readonly state: SessionState;
  readonly effects: readonly Effect[];
  /** step() threw something that is not an EngineError: the state is unchanged. */
  readonly crashed: boolean;
}

/** The reply and the flag of a turn the engine could not run. */
export function crashEffects(): Effect[] {
  return [
    { type: "SendText", text: systemText("system.generic_error") },
    { type: "FlagSession", reason: "incoherent_state", needsAttention: true },
  ];
}

/** D107: step() rethrows what is not an EngineError; the runtime answers and flags instead. */
export function stepSafely(
  state: SessionState,
  event: EngineEvent,
  campaign: CampaignDefinition,
  logger: Logger,
): SafeStep {
  try {
    return { ...step(state, event, campaign), crashed: false };
  } catch (error: unknown) {
    logger.error({ error: errorName(error) }, "engine threw");
    return { state, effects: crashEffects(), crashed: true };
  }
}
```

```ts
 * in the turn's transaction. Replies are queued in one go at the end, in order; the purge of a
 * StopSession with the delete policy comes last so the goodbye survives it (D109).

  ctx: ApplyContext,
  effects: readonly Effect[],

  const target = {
    campaign: ctx.campaign,
    language: outputLanguage(ctx.finalState.language, ctx.campaign),
  };
  const replies: OutboundMessageInput[] = [];
  let completed = false;
  let stopped = false;
  let needsAttention = false;
  let purge = false;
  let language: string | null = null;

    switch (effect.type) {
      case "SendText": {
        const resolved = await ctx.resolver.resolveSend(effect, target);
        if (resolved.missingParams.length > 0) {
          ctx.logger.warn(
            { turnId: ctx.turnId, text: describeTextRef(effect.text), missing: resolved.missingParams },
            "text with missing parameters",
          );

        replies.push({
          contactId: ctx.contact.id,
          senderNumberId: ctx.session.senderNumberId,
          sessionId: ctx.session.id,
          turnId: ctx.turnId,
          body: resolved.text,
          language: resolved.language,
          stepId: ctx.finalState.stepId,
          questionId: ctx.finalState.questionId,
        });
        break;
      }
      case "ApplyPatch":
        await applyProfileFields(tx, ctx.session.id, effect.source, ctx.turnId, effect.fields);
        break;
      case "RecordPatchRejections":
        // Log only: field and reason, never a value (spec §8.4).
        ctx.logger.info({ turnId: ctx.turnId, effect: describeEffect(effect) }, "patch rejected");
        break;
      case "MarkFieldUnresolved":
        await markFieldUnresolved(tx, ctx.session.id, effect.field, ctx.turnId);
        break;
      case "RecordConsent": {
        const shown = await ctx.resolver.resolve(effect.text, {
          campaign: ctx.campaign,
          language: effect.language,
        });
        await insertConsent(tx, {
          contactId: ctx.contact.id,
          channel: ctx.contact.channel,
          externalId: ctx.contact.externalId,
          sessionId: ctx.session.id,
          consentKey: effect.consentKey,
          textVersion: effect.textVersion,
          // The language the candidate actually read: Italian after a translation fallback.
          language: shown.language,
          textShown: shown.text,
          textShownIsCurated: shown.isCurated,
          dataController: {
            name: effect.dataController.name,
            privacyUrl: effect.dataController.privacyUrl,
          },
          outcome: effect.outcome,
          messageId: ctx.answeringMessageId,
          decidedAt: new Date(effect.at),
        });
        if (effect.consentKey === KUBRI_GLOBAL_CONSENT) {
          await setSharedWithGlobal(tx, ctx.session.id, effect.outcome === "accepted");
        }
        break;
      }
      case "SetLanguage":
        language = effect.language;
        await setPreferredLanguage(tx, ctx.contact.id, effect.language);
        break;
      case "CompleteSession":
        completed = true;
        await markProfileCompleted(tx, ctx.session.id, new Date(effect.at));
        break;
      case "StopSession":
        stopped = true;
        purge = effect.dataPolicy === "delete";
        break;

        break;

  if (purge) await purgeSessionData(tx, ctx.session.id);
```

```ts
/** A message from a person, already parsed by a channel (plan 09). */
export interface InboundMessage {
  readonly senderNumberId: string;
  readonly providerMessageId: string;
  readonly from: { readonly externalId: string; readonly phoneE164: string };
  readonly type: MessageKind;
  readonly body: string | null;

  message: InboundMessage,

  return inTransaction(
    deps.db,

        channel: "whatsapp",
        externalId: message.from.externalId,
        phoneE164: message.from.phoneE164,
      });
      const { created } = await insertInboundMessage(tx, {
        contactId: contact.id,
        senderNumberId: message.senderNumberId,
        providerMessageId: message.providerMessageId,
        type: message.type,
        body: message.body,
        payloadRaw: message.payloadRaw,
      });
      if (!created) return { duplicate: true };
      await registerInbound(tx, {
        contactId: contact.id,
        senderNumberId: message.senderNumberId,
        at: message.receivedAt,

      await deps.queue.enqueue(
        "process-contact",
        { contactId: contact.id, senderNumberId: message.senderNumberId },
        delaySeconds > 0 ? { startAfterSeconds: delaySeconds } : {},
        tx,
      );
      return { duplicate: false };
    },
    RECEIVE_TIMEOUT_MS,
  );
```

```ts
import type { RuntimeConfig } from "./config";

/**
 * How long to wait before running the turn: 0 = run now. The quiet time counts from the
 * newest message, the maximum from the oldest (D106). Dates are the database's: the same clock
 * for every message, so a skew with the worker's only shifts the wait a little.
 */
export function debounceWaitMs(
  config: Pick<RuntimeConfig, "debounceMs" | "debounceMaxWaitMs">,
  burst: readonly { readonly createdAt: Date }[],
  now: Date,
): number {
  if (config.debounceMs === 0 || burst.length === 0) return 0;
  const times = burst.map((m) => m.createdAt.getTime());
  const quietFor = now.getTime() - Math.max(...times);
  const waited = now.getTime() - Math.min(...times);
  if (quietFor >= config.debounceMs || waited >= config.debounceMaxWaitMs) return 0;
  return Math.min(config.debounceMs - quietFor, config.debounceMaxWaitMs - waited);
}
```

```ts
export interface ContactJob {
  readonly contactId: string;
  readonly senderNumberId: string;

export type ProcessResult =
  | "no_messages"
  | "rescheduled"
  | "ignored_media"
  | "no_campaign"
  | "replied"
  | "failed";

/** Spec §11.2 as one transaction (D102). Idempotent: a second run finds nothing to do. */
export function processContact(deps: RuntimeDeps, job: ContactJob): Promise<ProcessResult> {
  return inTransaction(deps.db, (tx) => runTurn(deps, tx, job), deps.config.turnTransactionMs);
}

interface Contact {
  readonly id: string;
  readonly channel: string;
  readonly externalId: string;
}

async function runTurn(deps: RuntimeDeps, tx: Tx, job: ContactJob): Promise<ProcessResult> {
  await lockKey(tx, `contact:${job.contactId}`);
  const burst = await receivedBurst(tx, job.contactId, job.senderNumberId);
  if (burst.length === 0) return "no_messages";
  const startedAt = deps.now();

  const wait = debounceWaitMs(deps.config, burst, startedAt);
  if (wait > 0) {
    await deps.queue.enqueue("process-contact", job, { startAfterSeconds: Math.ceil(wait / 1000) }, tx);
    return "rescheduled";
  }

  const contact = await tx.contact.findUniqueOrThrow({
    where: { id: job.contactId },
    select: { id: true, channel: true, externalId: true },
  });
  const turnId = (deps.newId ?? randomUUID)();
  const open = await findOpenSession(tx, contact.id, job.senderNumberId);
  const texts = burst.flatMap((m) => (m.type === "text" && m.body !== null ? [m.body] : []));

  if (texts.length === 0) {
    return finishQuietly(deps, tx, { turnId, sessionId: open?.id ?? null, burst, startedAt, outcome: "ignored_media" });
  }
  const text = texts.join("\n");
  const route = await chooseCampaign(deps, job.senderNumberId, text, open);
  if (route.kind === "none") {
    return finishQuietly(deps, tx, { turnId, sessionId: null, burst, startedAt, outcome: "no_campaign" });
  }

  const traces = new MemoryTraceSink();
  const prepared =
    route.kind === "stay"
      ? await continueSession(deps, tx, { open: route.session, text, turnId, traces })
      : await startSession(deps, tx, { contact, job, previous: open, campaign: route.campaign, startedAt });

  const { session, campaign, state, event, interpretation } = prepared;
  const result: SafeStep = state
    ? stepSafely(state, event, campaign.definition, deps.logger)
    : { state: prepared.fallbackState, effects: crashEffects(), crashed: true };
  const outcome: TurnOutcomeName = result.crashed ? "failed" : "replied";

  // The turn row comes first: messages, changes and traces point at it.
  await insertTurn(tx, {
    id: turnId,
    sessionId: session.id,
    inboundMessageIds: burst.map((m) => m.id),
    startedAt,
    completedAt: deps.now(),
    outcome,
  });
  await insertTraces(tx, traces.records);
  const effects = await applyEffects(
    {
      tx,
      queue: deps.queue,
      resolver: deps.resolver,
      logger: deps.logger,
      turnId,
      at: startedAt,
      contact,
      session,
      campaign: campaign.definition,
      finalState: result.state,
      answeringMessageId: burst.at(-1)?.id ?? null,
    },
    result.effects,
  );
  await saveSession(tx, session.id, {
    ...(state ? { state: encodeState(result.state) } : {}),
    language: result.state.language ?? session.language,
    status: nextStatus(session.status, effects),
    at: deps.now(),
    closeOpen: effects.stopped || result.state.phase === "closed",
    ...(effects.completed ? { completedAt: startedAt } : {}),
    ...(effects.stopped ? { stoppedAt: startedAt } : {}),
  });
  await markInboundProcessed(
    tx,
    burst.map((m) => ({
      id: m.id,
      sessionId: session.id,
      turnId,
      bodyRedacted: redactedCopy(m, interpretation, campaign),
    })),
  );
  if (effects.outbound > 0) {
    await deps.queue.enqueue("send-messages", job, {}, tx);
  }
  deps.logger.info(
    { turnId, sessionId: session.id, contactId: contact.id, outcome, replies: effects.outbound },
    "turn done",
  );
  return outcome;
}

type Route =
  | { readonly kind: "stay"; readonly session: SessionRecord }
  | { readonly kind: "new"; readonly campaign: LoadedCampaign }
  | { readonly kind: "none" };

/** D105: who answers this message — the open session, a new session, or nobody. */
async function chooseCampaign(
  deps: RuntimeDeps,
  senderNumberId: string,
  text: string,
  open: SessionRecord | null,
): Promise<Route> {
  if (open && open.status !== "completed") return { kind: "stay", session: open };
  const byKeyword = await findActiveCampaignByKeyword(deps.db, senderNumberId, text);
  if (byKeyword) return { kind: "new", campaign: byKeyword };
  // A completed session keeps the conversation unless a keyword opens another campaign.
  if (open) return { kind: "stay", session: open };
  const fallback = await findDefaultCampaign(deps.db, senderNumberId);
  return fallback ? { kind: "new", campaign: fallback } : { kind: "none" };
}

interface Prepared {
  readonly session: SessionRecord;
  readonly campaign: LoadedCampaign;
  /** null: the stored state could not be read (D104). */
  readonly state: SessionState | null;
  readonly fallbackState: SessionState;
  readonly event: EngineEvent;
  readonly interpretation: Interpretation | null;
}

async function mustFindVersion(deps: RuntimeDeps, versionId: string): Promise<LoadedCampaign> {
  const campaign = await findCampaignVersion(deps.db, versionId);
  if (!campaign) throw new Error(`campaign version ${versionId} is missing`);
  return campaign;
}

async function continueSession(
  deps: RuntimeDeps,
  tx: Tx,
  a: { open: SessionRecord; text: string; turnId: string; traces: MemoryTraceSink },
): Promise<Prepared> {
  const campaign = await mustFindVersion(deps, a.open.campaignVersionId);
  const profile = await loadProfile(tx, a.open.id);
  const fallbackState: SessionState = { ...initialSessionState(), language: parseLanguage(a.open.language) };
  let state: SessionState;
  try {
    state = decodeState(a.open.engineState, toSnapshot(profile));
  } catch {
    deps.logger.error({ sessionId: a.open.id }, "stored engine state cannot be read");
    const at = deps.now().toISOString();
    return {
      session: a.open, campaign, state: null, fallbackState,
      event: { type: "user_turn", at, text: a.text, interpretation: null }, interpretation: null,
    };
  }
  const history = await recentRedactedHistory(tx, a.open.id, deps.historyMessages);
  const { interpretation } = await interpretSafely(
    deps.interpreterFor(a.traces),
    { text: a.text, state, campaign: campaign.definition, history, turnId: a.turnId },
    deps.config.nluDeadlineMs,
    deps.logger,
  );
  return {
    session: a.open, campaign, state, fallbackState,
    event: { type: "user_turn", at: deps.now().toISOString(), text: a.text, interpretation },
    interpretation,
  };
}

/** A new session: the engine starts it with the welcome; the first message is not interpreted. */
async function startSession(
  deps: RuntimeDeps,
  tx: Tx,
  a: { contact: Contact; job: ContactJob; previous: SessionRecord | null; campaign: LoadedCampaign; startedAt: Date },
): Promise<Prepared> {
  if (a.previous) await closeOpenKey(tx, a.previous.id);
  const state = initialSessionState();
  const session = await createSession(tx, {
    contactId: a.contact.id,
    senderNumberId: a.job.senderNumberId,
    campaignVersionId: a.campaign.versionId,
    state: encodeState(state),
    at: a.startedAt,
  });
  return {
    session, campaign: a.campaign, state, fallbackState: state,
    event: { type: "session_started", at: a.startedAt.toISOString() }, interpretation: null,
  };
}

function parseLanguage(language: string | null) {
  return language !== null && /^[a-z]{2}$/.test(language) ? language : null;
}

function nextStatus(current: SessionStatusName, effects: EffectsOutcome): SessionStatusName {
  if (effects.stopped) return "stopped";
  if (effects.completed) return "completed";
  if (effects.needsAttention && current === "active") return "needs_attention";
  return current;
}

function redactedCopy(m: BurstMessage, interpretation: Interpretation | null, campaign: LoadedCampaign): string | null {
  if (m.body === null) return null;
  return redactWithEvidence(m.body, interpretation, campaign.definition.customFields);
}

async function finishQuietly(
  deps: RuntimeDeps,
  tx: Tx,
  a: { turnId: string; sessionId: string | null; burst: readonly BurstMessage[]; startedAt: Date; outcome: "ignored_media" | "no_campaign" },
): Promise<ProcessResult> {
  await insertTurn(tx, {
    id: a.turnId,
    sessionId: a.sessionId,
    inboundMessageIds: a.burst.map((m) => m.id),
    startedAt: a.startedAt,
    completedAt: deps.now(),
    outcome: a.outcome,
  });
  await markInboundProcessed(
    tx,
    a.burst.map((m) => ({
      id: m.id,
      sessionId: a.sessionId,
      turnId: a.turnId,
      bodyRedacted: m.body === null ? null : redactContacts(m.body),
    })),
  );
  // Never silent without a recorded reason (CLAUDE.md): the turn row and this line are it.
  deps.logger.info({ turnId: a.turnId, sessionId: a.sessionId, outcome: a.outcome }, "turn without a reply");
  return a.outcome;
}
```

```ts
import type { Logger } from "pino";
import type { ChannelAdapter, OutboundSender, SendOutcome } from "../channels/channel";
import { step } from "../engine/step";
import type { Database } from "../store/db";
import { inTransaction } from "../store/db";
import { findCampaignVersion } from "../store/campaigns";
import {
  claimNextOutbound,
  finishSend,
  type ClaimedMessage,
  type SendKey,
} from "../store/messages";
import type { JobQueue } from "../store/queue";
import { findSessionById, markNeedsAttention } from "../store/sessions";
import { recordFlag } from "./apply-effects";
import type { RuntimeConfig } from "./config";
import { decodeState } from "./state-codec";

export interface SendDeps {
  readonly db: Database;
  readonly config: RuntimeConfig;
  readonly logger: Logger;
  readonly queue: JobQueue;
  readonly channelFor: (provider: OutboundSender["provider"]) => ChannelAdapter;
  readonly now: () => Date;
}

/** Thrown to make pg-boss retry the job with its backoff (D108). */
export class TransientSendError extends Error {
  constructor(readonly code: string) {
    super(`transient send failure: ${code}`);
    this.name = "TransientSendError";
  }
}

async function targetOf(deps: SendDeps, message: ClaimedMessage) {
  const [contact, sender] = await Promise.all([
    deps.db.contact.findUniqueOrThrow({ where: { id: message.contactId } }),
    deps.db.senderNumber.findUniqueOrThrow({ where: { id: message.senderNumberId } }),
  ]);
  return {
    to: { externalId: contact.externalId, phoneE164: contact.phoneE164 },
    sender: {
      id: sender.id,
      slug: sender.slug,
      provider: sender.provider,
      providerConfig: sender.providerConfig,
    } satisfies OutboundSender,
  };
}

async function sendOnce(deps: SendDeps, message: ClaimedMessage): Promise<SendOutcome> {
  const { to, sender } = await targetOf(deps, message);
  try {
    return await deps.channelFor(sender.provider).send({
      clientMessageId: message.id,
      sender,
      to,
      text: message.body,
    });
  } catch {
    // An adapter that throws is a broken connection, not a verdict on the message.
    return { ok: false, kind: "transient", code: "channel_exception" };
  }
}

/**
 * Spec §11.3: after a definitive error the engine hears about it (`outbound_failed`), which
 * flags the session. Only the flags are applied: the reply to the candidate is the one that
 * could not be sent.
 */
async function reportFailure(deps: SendDeps, message: ClaimedMessage): Promise<void> {
  if (message.sessionId === null) return;
  const sessionId = message.sessionId;
  await inTransaction(
    deps.db,
    async (tx) => {
      const session = await findSessionById(tx, sessionId);
      if (!session) return;
      const campaign = await findCampaignVersion(deps.db, session.campaignVersionId);
      if (!campaign) return;
      // The profile is not needed to run outbound_failed: the state is never saved here.
      const state = decodeState(session.engineState, {});
      const result = step(state, { type: "outbound_failed", at: deps.now().toISOString() }, campaign.definition);
      for (const effect of result.effects) {
        if (effect.type !== "FlagSession") continue;
        await recordFlag(tx, { sessionId, turnId: message.turnId, logger: deps.logger }, effect);
        if (effect.needsAttention) await markNeedsAttention(tx, sessionId);
      }
    },
    15_000,
  );
}

/**
 * Sends a contact's queued messages in order, until none is left, one is in someone else's
 * hands, or one fails (D108). Safe to run twice at once: the claim serializes the senders.
 */
export async function sendMessages(deps: SendDeps, key: SendKey): Promise<void> {
  for (;;) {
    const claim = await claimNextOutbound(deps.db, key, deps.now(), deps.config.sendLeaseMs);
    if (claim === null) return;
    if (claim === "busy") {
      // The holder keeps going; this is only a safety net if it died before finishing.
      await deps.queue.enqueue("send-messages", key, {
        startAfterSeconds: Math.ceil(deps.config.sendLeaseMs / 1000),
      });
      return;
    }
    const outcome = await sendOnce(deps, claim);
    if (outcome.ok) {
      await finishSend(deps.db, claim, {
        kind: "sent",
        providerMessageId: outcome.providerMessageId,
        at: deps.now(),
      });
      continue;
    }
    if (outcome.kind === "transient" && claim.attempts < deps.config.sendMaxAttempts) {
      await finishSend(deps.db, claim, { kind: "transient", code: outcome.code });
      throw new TransientSendError(outcome.code);
    }
    const code = outcome.kind === "transient" ? "too_many_attempts" : outcome.code;
    await finishSend(deps.db, claim, { kind: "permanent", code, at: deps.now() });
    deps.logger.warn({ messageId: claim.id, sessionId: claim.sessionId, code }, "message failed for good");
    await reportFailure(deps, claim);
    return;
  }
}
```

```ts
};

/** What a cooperative candidate would write at the point where the session stands. */
export async function answerFor(db: Database, campaign: CampaignDefinition, sessionId: string): Promise<string> {
  const session = await db.session.findUniqueOrThrow({ where: { id: sessionId } });
  const profile = parseStoredProfile(await db.candidateProfile.findUniqueOrThrow({ where: { sessionId } }));
  const state = decodeState(session.engineState, toSnapshot(profile));
  if (state.phase === "language") return "italiano";
  const step = campaign.flow.find((s) => s.id === state.stepId);
  switch (step?.type) {
    case "consent":
    case "cv_offer":
      return "sì";
    case "choice":
      return step.options[0]?.id ?? "1";
    case "questions": {
      const question = step.questions.find((q) => q.id === state.questionId);
      const def = question ? resolveField(question.field, campaign.customFields) : undefined;
      if (!def) return "boh";
      if (def.type === "enum") return def.options?.[0] ?? "boh";
      return SAMPLES[def.format ?? def.type] ?? "boh";
    }
    default:
      return "ok";
  }
}
```
