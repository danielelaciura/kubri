# Piano 09 — Canale WhatsApp, messaggi interattivi e ingresso web

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Collegare il runtime a WhatsApp: modulo `channels/meta-cloud` (firma, parsing,
invio, classificazione degli errori), processo web con deduplica e scarti, stati di consegna,
finestra delle 24 ore, e **messaggi interattivi**: quando il bot chiede una scelta chiusa
(lingua, consenso, sì/no, opzioni) il candidato la fa toccando un bottone o una voce di un
elenco, invece di scrivere. La risposta a un tocco è **deterministica**: non passa dall'LLM.

**Architecture:** Le scelte chiuse non sono un nuovo effetto del motore. Cosa il candidato può
toccare è determinato dallo stato (passaggio, conferma in sospeso, domanda), quindi una funzione
**pura** `awaitedChoices(state, campaign)` in `src/engine/choices.ts` lo calcola, e il runtime
lo attacca all'ultimo messaggio del turno. Il canale sceglie la forma (fino a 3 voci: bottoni;
fino a 10: elenco) e il modulo `channels/meta-cloud` la traduce nel JSON della Cloud API. In
entrata il parser riconosce `button_reply` e `list_reply`; il runtime riconosce l'`id` tra le
scelte attese e costruisce un'`Interpretation` sintetica. Il processo web (`src/ingress/`) usa
`node:http`, verifica la firma sul corpo grezzo, salva con `receiveInbound` (piano 08) e
risponde subito.

**Tech Stack:** TypeScript strict, `node:http`, `node:crypto`, `fetch` di Node 22, Zod 4,
Prisma 7, Vitest 4. Nessuna dipendenza nuova.

**Spec:** §5.2 (passaggi), §7.1 (`SendChoice`, qui superato da D112), §11.1 (processo web),
§11.3 (invio), §12 (non toccato), §13 (errori), §16.3 (sicurezza), §17 (bottoni interattivi:
anticipati nella v1), D22, D41, D49, D105, D108.

## Decisioni prese in questo piano (da riportare nella spec, §2, come D112–D121)

Il piano 08 ha preso D102–D111.

- **D112 — Le scelte chiuse sono derivate dallo stato, non un effetto.** Nessun nuovo effetto del
  motore (`SendChoice` del §7.1 non serve): `awaitedChoices(state, campaign)`, pura, dice quali
  risposte chiuse il motore aspetta *adesso*; il runtime le attacca all'ultimo messaggio del
  turno, che è sempre la domanda in attesa. Un turno finito in errore non porta mai un widget.
- **D113 — Dove compare un widget.** Lingua (elenco di 10 lingue con il nome nella propria
  lingua); conferme in sospeso (Sì / No); consenso (Accetto / Non accetto); passaggio `choice`
  (opzioni con `label`; `yes`, `no`, `idk` hanno l'etichetta del catalogo); `cv_offer` e
  riproposta del CV (Sì / No); domande `bool` (Sì / No) ed `enum` (le opzioni, se sono al più 10 e
  di al più 24 caratteri). Altrove nessuno. Il testo libero resta sempre possibile: il widget è
  una scorciatoia, non un obbligo.
- **D114 — Un tocco è una risposta deterministica.** Se la raffica contiene solo tocchi e l'`id`
  è tra le scelte attese, l'`Interpretation` è sintetica (confidenza 1, nessuna chiamata all'LLM,
  nessuna traccia): `choice` per consensi e conferme, `answer` con una patch per bool ed enum,
  `answer` con la lingua per l'elenco delle lingue. Un `id` non più atteso (tocco su un widget
  vecchio) ricade sul testo del titolo, interpretato dall'NLU come se l'avesse scritto.
- **D115 — Forma sul canale.** 2–3 voci: bottoni (titolo ≤ 20 caratteri); 4–10: elenco (titolo
  ≤ 24, pulsante ≤ 20); 0, 1 o più di 10: testo semplice. Corpo ≤ 1024 caratteri: se il messaggio
  è più lungo si invia come testo e il widget parte in un messaggio breve ("Scegli una risposta:").
  I titoli più lunghi del limite si troncano con "…". Un canale che non supporta i widget
  (`supportsInteractive: false`) riceve solo il testo.
- **D116 — Salvataggio.** Un messaggio interattivo in uscita ha `type = interactive` e
  `Message.interactive` con i titoli già risolti nella lingua del candidato; uno in entrata ha
  `type = interactive`, `body` = titolo toccato e `replyId` = id (il parser Meta non esce dal
  canale).
- **D117 — Processo web.** `node:http`, tre rotte: `GET /webhooks/whatsapp` (verifica),
  `POST /webhooks/whatsapp`, `GET /health`. La firma `X-Hub-Signature-256` si verifica sul corpo
  grezzo con confronto a tempo costante: non valida → 401. JSON illeggibile, payload non
  riconosciuto, messaggio non interpretabile o numero sconosciuto → `InboundDeadLetter` e 200.
  Database non raggiungibile → 500 (Meta ritenta; la deduplica rende il ritentativo sicuro).
- **D118 — Parsing.** Si leggono **tutte** le entry, i cambiamenti, i messaggi e gli stati (Make
  leggeva solo il primo). Ogni messaggio è salvato, di qualunque tipo; il motore parte solo per
  testo e tocchi. Reazioni e cambiamenti di altri campi si ignorano. Un tipo sconosciuto vale
  `unsupported`.
- **D119 — Invio e errori.** Cloud API con versione configurabile (`META_GRAPH_VERSION`). Il token è
  il valore della variabile d'ambiente il cui **nome** sta nella configurazione del numero. Errori:
  limiti di richieste, 5xx, timeout e rete → temporanei; finestra scaduta (131047), numero non
  raggiungibile (131026), non in elenco (131030), parametri non validi (100), token non valido
  (190) → definitivi. La finestra delle 24 ore si controlla **prima** della chiamata
  (`freeFormWindowMs` del canale), senza sprecarla.
- **D120 — Stati di consegna.** `delivered` e `read` fanno avanzare un messaggio solo in avanti
  (`sent` → `delivered` → `read`); `failed` lo porta a `failed` e, se ha una sessione, scatta
  l'evento `outbound_failed` del motore. Stati per messaggi sconosciuti si ignorano.
- **D121 — Lettura, "sta scrivendo" e media.** All'inizio di `process-contact`, fuori dalla
  transazione e senza far fallire nulla, si manda la conferma di lettura con l'indicatore "sta
  scrivendo". Audio, immagini e documenti (con una sessione aperta) ricevono "per ora scrivimi in
  testo"; come primo messaggio aprono comunque la sessione col benvenuto.

### Task 3: Scelte attese (`awaitedChoices`) e risposta a un tocco

**Concetto: dallo stato alle scelte.** Il motore sa sempre cosa sta aspettando: una conferma
sì/no, un consenso, una domanda. Quindi può dire quali risposte *chiuse* sono possibili, senza
altro input. Ogni scelta porta tre cose: l'`id` che il canale rimanda al tocco, l'etichetta da
mostrare e il **significato** per il motore (una scelta, un valore per un campo, una lingua).
La stessa funzione serve due volte: all'uscita per costruire il widget e all'ingresso per
riconoscere il tocco. Un tocco su un widget vecchio non trova più il suo `id` tra le scelte attese
e viene trattato come testo (D114).

```ts
import type { CampaignDefinition } from "../campaigns/schema/campaign";
import {
  MAX_CHOICE_LABEL_LENGTH,
  type ChoiceStep,
  type QuestionsStep,
} from "../campaigns/schema/steps";
import type { LanguageCode, LocalizedText } from "../i18n/localized-text";
import { resolveField } from "../profile/field-ref";
import type { Interpretation } from "./interpretation";
import type { SessionState } from "./state";

/** Catalog texts for the buttons (src/i18n/system-catalog.ts holds the wording). */
export type ChoiceLabelKey =
  "choice.yes" | "choice.no" | "choice.idk" | "choice.accepted" | "choice.declined";

export type ChoiceLabel =
  | { readonly kind: "catalog"; readonly key: ChoiceLabelKey }
  /** A short localized text, translated like any label (an option label, an enum value). */
  | { readonly kind: "text"; readonly text: LocalizedText }
  /** Shown as it is: the name of a language in that language. */
  | { readonly kind: "literal"; readonly text: string };

/** What a tap means to the engine (D114). */
export type ChoiceMeaning =
  | { readonly kind: "choice"; readonly choice: string }
  | { readonly kind: "value"; readonly field: string; readonly value: unknown }
  | { readonly kind: "language"; readonly code: LanguageCode };

export interface OfferedChoice {
  /** What the channel sends back on a tap. Unique within the offer. */
  readonly id: string;
  readonly label: ChoiceLabel;
  readonly meaning: ChoiceMeaning;
}

export interface ChoiceOffer {
  readonly options: readonly OfferedChoice[];
  /** The catalog text of the button that opens a list. */
  readonly listButton: "choice.list_button" | "choice.language_button";
}

/** WhatsApp lists hold ten rows. */
export const MAX_OFFERED_CHOICES = 10;

/** The ten languages offered at the start (D113), each named in its own language. */
export const OFFERED_LANGUAGES: readonly { readonly code: LanguageCode; readonly name: string }[] = [
  { code: "it", name: "Italiano" },
  { code: "en", name: "English" },
  { code: "ar", name: "العربية" },
  { code: "fr", name: "Français" },
  { code: "es", name: "Español" },
  { code: "uk", name: "Українська" },
  { code: "ro", name: "Română" },
  { code: "sq", name: "Shqip" },
  { code: "bn", name: "বাংলা" },
  { code: "ur", name: "اردو" },
];

const catalog = (key: ChoiceLabelKey): ChoiceLabel => ({ kind: "catalog", key });
const choice = (id: string, key: ChoiceLabelKey): OfferedChoice => ({
  id,
  label: catalog(key),
  meaning: { kind: "choice", choice: id },
});

const YES = choice("yes", "choice.yes");
const NO = choice("no", "choice.no");
const YES_NO: readonly OfferedChoice[] = [YES, NO];
const CONSENT: readonly OfferedChoice[] = [
  choice("accepted", "choice.accepted"),
  choice("declined", "choice.declined"),
];

const LIST: ChoiceOffer["listButton"] = "choice.list_button";
const offer = (options: readonly OfferedChoice[]): ChoiceOffer => ({ options, listButton: LIST });

const CATALOG_OPTION_LABELS: Readonly<Record<string, ChoiceLabelKey>> = {
  yes: "choice.yes",
  no: "choice.no",
  idk: "choice.idk",
};

function choiceStepOffer(step: ChoiceStep): ChoiceOffer | null {
  if (step.options.length > MAX_OFFERED_CHOICES) return null;
  const options: OfferedChoice[] = [];
  for (const option of step.options) {
    const key = Object.hasOwn(CATALOG_OPTION_LABELS, option.id)
      ? CATALOG_OPTION_LABELS[option.id]
      : undefined;
    const label: ChoiceLabel | undefined = option.label
      ? { kind: "text", text: option.label }
      : key
        ? catalog(key)
        : undefined;
    // One option without a label and the whole question is asked in plain text.
    if (!label) return null;
    options.push({ id: option.id, label, meaning: { kind: "choice", choice: option.id } });
  }
  return offer(options);
}

function questionOffer(
  step: QuestionsStep,
  questionId: string | null,
  campaign: CampaignDefinition,
): ChoiceOffer | null {
  const question = step.questions.find((q) => q.id === questionId);
  const def = question ? resolveField(question.field, campaign.customFields) : undefined;
  if (!question || !def || def.systemOnly) return null;
  if (def.type === "bool") {
    return offer([
      { ...YES, meaning: { kind: "value", field: question.field, value: true } },
      { ...NO, meaning: { kind: "value", field: question.field, value: false } },
    ]);
  }
  const values = def.type === "enum" ? def.options : undefined;
  if (!values || values.length < 2 || values.length > MAX_OFFERED_CHOICES) return null;
  // A cut label would make two options look alike: such an enum is asked in plain text.
  if (values.some((value) => Array.from(value).length > MAX_CHOICE_LABEL_LENGTH)) return null;
  return offer(
    values.map((value) => ({
      id: `value:${value}`,
      label: { kind: "text", text: { it: value } },
      meaning: { kind: "value", field: question.field, value },
    })),
  );
}

/**
 * D112, D113: the closed answers the engine is waiting for right now, from the state alone.
 * null = a free-text answer (or nothing) is expected. The same function builds the widget on
 * the way out and recognizes the tap on the way in.
 */
export function awaitedChoices(state: SessionState, campaign: CampaignDefinition): ChoiceOffer | null {
  if (state.phase === "closed") return null;
  if (state.pendingConfirmation) return offer(YES_NO);
  if (state.phase === "language") {
    return {
      listButton: "choice.language_button",
      options: OFFERED_LANGUAGES.map(({ code, name }) => ({
        id: `lang:${code}`,
        label: { kind: "literal", text: name },
        meaning: { kind: "language", code },
      })),
    };
  }
  const step = state.stepId === null ? undefined : campaign.flow.find((s) => s.id === state.stepId);
  if (!step) return null;
  // After the interview only a CV regeneration being offered waits for a yes/no (D44).
  if (state.phase === "post_completion") return step.type === "cv_offer" ? offer(YES_NO) : null;
  switch (step.type) {
    case "consent":
      return offer(CONSENT);
    case "cv_offer":
      return offer(YES_NO);
    case "choice":
      return choiceStepOffer(step);
    case "questions":
      return questionOffer(step, state.questionId, campaign);
    case "message":
    case "end":
      return null;
  }
}

/** A tap, as the engine understands it: full confidence, no LLM involved (D114). */
export function interpretationForChoice(
  option: OfferedChoice,
  language: LanguageCode,
  title: string,
): Interpretation {
  const base = {
    language: { code: language, confidence: 1 },
    patch: [],
    currentQuestion: { completeness: "absent" as const },
  };
  switch (option.meaning.kind) {
    case "choice":
      return { ...base, intent: "choice", choice: option.meaning.choice };
    case "value":
      return {
        ...base,
        intent: "answer",
        patch: [{ field: option.meaning.field, value: option.meaning.value, confidence: 1, evidence: title }],
        currentQuestion: { completeness: "complete" },
      };
    case "language":
      return { ...base, language: { code: option.meaning.code, confidence: 1 }, intent: "answer" };
  }
}

/** The interpretation of a tap, or null when its id is not one of the awaited choices. */
export function interpretReply(
  state: SessionState,
  campaign: CampaignDefinition,
  reply: { readonly id: string; readonly title: string },
): Interpretation | null {
  const option = awaitedChoices(state, campaign)?.options.find((o) => o.id === reply.id);
  if (!option) return null;
  return interpretationForChoice(option, state.language ?? campaign.defaultLanguage, reply.title);
}
```

```ts
  sent: [],
  delivered: ["sent"],

  failed: ["sent", "delivered"],

  readonly status: DeliveryStatus;
  readonly at: Date;
  /** The provider's error code, for `failed`. */
  readonly errorCode: string | null;
}

export async function applyDeliveryStatus(
  tx: Tx,
  update: DeliveryUpdate,

  const from = MOVES_FROM[update.status];

    update.status === "failed"
      ? { status: "failed" as const, failedAt: update.at, errorCode: update.errorCode }
      : update.status === "read"
        ? { status: "read" as const, readAt: update.at }
        : { status: "delivered" as const, deliveredAt: update.at };
  const result =
    from.length === 0 || update.status === "sent"
      ? { count: 0 }
      : await tx.message.updateMany({
          where: { providerMessageId: update.providerMessageId, direction: "outbound", status: { in: [...from] } },
          data,
        });
  const row = await tx.message.findUnique({
    where: { providerMessageId: update.providerMessageId },
    select: { sessionId: true, turnId: true },
  });
  return { updated: result.count === 1, sessionId: row?.sessionId ?? null, turnId: row?.turnId ?? null };
}
```

```ts
import type { OutboundChoices } from "./channel";

// WhatsApp's limits for interactive messages (D115).
export const INTERACTIVE_BODY_LIMIT = 1024;
export const BUTTON_COUNT_LIMIT = 3;
export const BUTTON_TITLE_LIMIT = 20;
export const ROW_COUNT_LIMIT = 10;
export const ROW_TITLE_LIMIT = 24;
export const LIST_BUTTON_LIMIT = 20;

/** Cuts by characters, not UTF-16 units (Arabic and Bengali are not one unit per letter). */
export function truncate(text: string, max: number): string {
  const characters = Array.from(text);
  return characters.length <= max ? text : `${characters.slice(0, max - 1).join("")}…`;
}

export interface WidgetOption {
  readonly id: string;
  readonly title: string;
}

export type WidgetShape =
  | { readonly kind: "buttons"; readonly buttons: readonly WidgetOption[] }
  | { readonly kind: "list"; readonly button: string; readonly rows: readonly WidgetOption[] }
  | { readonly kind: "none" };

const cut = (picks: readonly WidgetOption[], max: number): WidgetOption[] =>
  picks.map(({ id, title }) => ({ id, title: truncate(title, max) }));

/** D115: buttons for 2–3 options, a list for 4–10, plain text otherwise. */
export function shapeChoices(choices: OutboundChoices): WidgetShape {
  const count = choices.options.length;
  if (count < 2 || count > ROW_COUNT_LIMIT) return { kind: "none" };
  if (count <= BUTTON_COUNT_LIMIT) {
    return { kind: "buttons", buttons: cut(choices.options, BUTTON_TITLE_LIMIT) };
  }
  return {
    kind: "list",
    button: truncate(choices.listButton, LIST_BUTTON_LIMIT),
    rows: cut(choices.options, ROW_TITLE_LIMIT),
  };
}
```

```ts
import { createHmac, timingSafeEqual } from "node:crypto";

const PREFIX = "sha256=";

/** The header Meta sends: "sha256=" and the hex HMAC-SHA256 of the raw body. */
export function signBody(appSecret: string, rawBody: Buffer): string {
  return `${PREFIX}${createHmac("sha256", appSecret).update(rawBody).digest("hex")}`;
}

/**
 * Spec §16.3: checked on the raw bytes, before any parsing, in constant time. A header that
 * is missing, has another prefix or is not hex of the right length is simply not valid.
 */
export function verifySignature(
  appSecret: string,
  rawBody: Buffer,
  header: string | undefined,
): boolean {
  if (!header?.startsWith(PREFIX)) return false;
  const expected = createHmac("sha256", appSecret).update(rawBody).digest();
  const given = Buffer.from(header.slice(PREFIX.length), "hex");
  return given.length === expected.length && timingSafeEqual(given, expected);
}

/** The GET Meta sends once when the webhook is set up: echo `hub.challenge` if the token matches. */
export function verifyChallenge(query: URLSearchParams, verifyToken: string): string | null {
  const challenge = query.get("hub.challenge");
  if (query.get("hub.mode") !== "subscribe" || query.get("hub.verify_token") !== verifyToken) {
    return null;
  }
  return challenge === null || challenge === "" ? null : challenge;
}
```

```ts
import { z } from "zod";

export type ParsedKind = "text" | "audio" | "image" | "document" | "interactive" | "location" | "unsupported";

export interface ParsedMessage {
  readonly phoneNumberId: string;
  readonly providerMessageId: string;
  readonly from: { readonly externalId: string; readonly phoneE164: string };
  readonly type: ParsedKind;
  readonly body: string | null;
  /** A tap on a button or a list row (D114). */
  readonly reply: { readonly id: string; readonly title: string } | null;
  readonly receivedAt: Date;
  /** The message as Meta sent it, for the audit trail and the dead letters. */
  readonly raw: unknown;
}

export interface ParsedStatus {
  readonly phoneNumberId: string;
  readonly providerMessageId: string;
  readonly status: "sent" | "delivered" | "read" | "failed";
  readonly at: Date;
  readonly errorCode: number | null;
}

export interface ParsedPayload {
  readonly messages: ParsedMessage[];
  readonly statuses: ParsedStatus[];
  /** Other fields' changes, reactions: nothing to answer, nothing to keep. */
  readonly ignored: number;
  /** Items that looked like messages or statuses but could not be read: kept as dead letters. */
  readonly rejected: unknown[];
}

const Envelope = z.object({
  object: z.literal("whatsapp_business_account"),
  entry: z.array(z.object({ changes: z.array(z.object({ field: z.string(), value: z.unknown() })) })),
});

const Value = z.object({
  metadata: z.object({ phone_number_id: z.string() }),
  messages: z.array(z.unknown()).optional(),
  statuses: z.array(z.unknown()).optional(),
});

const Message = z.object({
  from: z.string().regex(/^\d+$/),
  id: z.string().min(1),
  timestamp: z.string().regex(/^\d+$/),
  type: z.string(),
  text: z.object({ body: z.string() }).optional(),
  interactive: z
    .object({
      type: z.string(),
      button_reply: z.object({ id: z.string(), title: z.string() }).optional(),
      list_reply: z.object({ id: z.string(), title: z.string() }).optional(),
    })
    .optional(),
  button: z.object({ text: z.string() }).optional(),
});

const Status = z.object({
  id: z.string().min(1),
  status: z.string(),
  timestamp: z.string().regex(/^\d+$/),
  errors: z.array(z.object({ code: z.number() })).optional(),
});

const SIMPLE: Readonly<Record<string, ParsedKind>> = {
  audio: "audio",
  image: "image",
  document: "document",
  location: "location",
};

const STATUSES: ReadonlySet<string> = new Set(["sent", "delivered", "read", "failed"]);

const at = (seconds: string): Date => new Date(Number(seconds) * 1000);

function readMessage(
  phoneNumberId: string,
  item: z.infer<typeof Message>,
  raw: unknown,
): ParsedMessage | "ignored" {
  const base = {
    phoneNumberId,
    providerMessageId: item.id,
    from: { externalId: item.from, phoneE164: `+${item.from}` },
    receivedAt: at(item.timestamp),
    raw,
  };
  if (item.type === "reaction") return "ignored";
  if (item.type === "text" && item.text) {
    return { ...base, type: "text", body: item.text.body, reply: null };
  }
  // A quick-reply button of a template arrives as type "button": its text is what was tapped.
  if (item.type === "button" && item.button) {
    return { ...base, type: "text", body: item.button.text, reply: null };
  }
  if (item.type === "interactive" && item.interactive) {
    const tap = item.interactive.button_reply ?? item.interactive.list_reply;
    if (tap) return { ...base, type: "interactive", body: tap.title, reply: tap };
  }
  return { ...base, type: SIMPLE[item.type] ?? "unsupported", body: null, reply: null };
}

/**
 * D118: every entry, change, message and status. null = not a WhatsApp payload at all. The
 * tolerant schemas ignore fields Meta adds; an item that does not fit is kept in `rejected`.
 */
export function parseWebhook(json: unknown): ParsedPayload | null {
  const envelope = Envelope.safeParse(json);
  if (!envelope.success) return null;
  const parsed: ParsedPayload = { messages: [], statuses: [], ignored: 0, rejected: [] };
  for (const entry of envelope.data.entry) {
    for (const change of entry.changes) {
      const value = change.field === "messages" ? Value.safeParse(change.value) : null;
      if (!value?.success) {
        if (change.field === "messages") parsed.rejected.push(change.value);
        else parsed.ignored += 1;
        continue;
      }
      const phoneNumberId = value.data.metadata.phone_number_id;
      for (const raw of value.data.messages ?? []) {
        const item = Message.safeParse(raw);
        const message = item.success ? readMessage(phoneNumberId, item.data, raw) : null;
        if (message === "ignored") parsed.ignored += 1;
        else if (message) parsed.messages.push(message);
        else parsed.rejected.push(raw);
      }
      for (const raw of value.data.statuses ?? []) {
        const item = Status.safeParse(raw);
        if (!item.success || !STATUSES.has(item.data.status)) {
          parsed.rejected.push(raw);
          continue;
        }
        parsed.statuses.push({
          phoneNumberId,
          providerMessageId: item.data.id,
          status: item.data.status as ParsedStatus["status"],
          at: at(item.data.timestamp),
          errorCode: item.data.errors?.[0]?.code ?? null,
        });
      }
    }
  }
  return parsed;
}
```

```ts
export function sendBody(message: OutboundText): Record<string, unknown> {

  const shape = message.choices ? shapeChoices(message.choices) : ({ kind: "none" } as const);

    case "buttons":
      return {
        ...HEADER,
        to,
        type: "interactive",
        interactive: {
          type: "button",
          body,
          action: {
            buttons: shape.buttons.map(({ id, title }) => ({ type: "reply", reply: { id, title } })),
          },
        },
      };
    case "list":
      return {
        ...HEADER,
        to,
        type: "interactive",
        interactive: {
          type: "list",
          body,
          action: { button: shape.button, sections: [{ rows: shape.rows }] },
        },
      };
    case "none":
      return { ...HEADER, to, type: "text", text: { preview_url: false, body: message.text } };
  }
}
```

```ts
import type { SendOutcome } from "../channel";

type Failure = Extract<SendOutcome, { ok: false }>;

// Meta's Graph API error codes. Documented ones only; anything else follows the HTTP status.
const PERMANENT: Readonly<Record<number, string>> = {
  131047: "outside_window", // re-engagement: the 24 hour window is closed
  131026: "not_reachable", // undeliverable
  131030: "not_allowed", // recipient not in the allowed list (test numbers)
  131021: "to_self",
  131051: "unsupported_type",
  100: "invalid_request",
  190: "auth_failed", // token expired or invalid: an operator must act
  10: "permission",
  200: "permission",
};

const TRANSIENT: Readonly<Record<number, string>> = {
  130429: "rate_limited",
  131056: "rate_limited",
  80007: "rate_limited",
  4: "rate_limited",
  17: "rate_limited",
  32: "rate_limited",
  613: "rate_limited",
  131000: "meta_unavailable",
  131016: "meta_unavailable",
  1: "meta_unavailable",
  2: "meta_unavailable",
};

function errorCode(body: unknown): number | undefined {
  if (typeof body !== "object" || body === null || !("error" in body)) return undefined;
  const error = body.error;
  if (typeof error !== "object" || error === null || !("code" in error)) return undefined;
  return typeof error.code === "number" ? error.code : undefined;
}

/** D119: temporary (try again, then give up) or permanent (stop the turn's other messages). */
export function classifyError(httpStatus: number, body: unknown): Failure {
  const code = errorCode(body);
  if (code !== undefined && Object.hasOwn(TRANSIENT, code)) {
    return { ok: false, kind: "transient", code: TRANSIENT[code] ?? "meta_unavailable" };
  }
  if (code !== undefined && Object.hasOwn(PERMANENT, code)) {
    return { ok: false, kind: "permanent", code: PERMANENT[code] ?? "meta_error" };
  }
  if (httpStatus === 429) return { ok: false, kind: "transient", code: "rate_limited" };
  if (httpStatus >= 500 || httpStatus === 408) {
    return { ok: false, kind: "transient", code: `http_${httpStatus}` };
  }
  return { ok: false, kind: "permanent", code: code === undefined ? `http_${httpStatus}` : `meta_${code}` };
}
```

```ts
import { z } from "zod";
import { MetaProviderConfigSchema } from "../provider-config";
import type { ChannelAdapter, OutboundSender, OutboundText, SendOutcome } from "../channel";
import { classifyError } from "./errors";
import { acknowledgeBody, sendBody } from "./requests";

export type FetchLike = (url: string, init: RequestInit) => Promise<Response>;

export interface MetaChannelOptions {
  /** Graph API version, e.g. "v23.0" (META_GRAPH_VERSION). */
  readonly graphVersion: string;
  /** Value of the secret NAMED in the number's configuration; undefined when not set. */
  readonly secret: (name: string) => string | undefined;
  /** Injected by tests: they never reach Meta. */
  readonly fetch?: FetchLike;
  readonly timeoutMs?: number;
}

const ResponseSchema = z.object({ messages: z.array(z.object({ id: z.string().min(1) })).min(1) });

const DAY_MS = 24 * 60 * 60 * 1000;
const DEFAULT_TIMEOUT_MS = 10_000;
const ACK_TIMEOUT_MS = 3_000;

type Prepared = { ok: true; url: string; token: string } | Extract<SendOutcome, { ok: false }>;

export function createMetaCloudChannel(options: MetaChannelOptions): ChannelAdapter {
  const fetchImpl = options.fetch ?? fetch;

  /** The endpoint and token of a number; a broken configuration is a permanent failure (D119). */
  function prepare(sender: OutboundSender): Prepared {
    const config = MetaProviderConfigSchema.safeParse(sender.providerConfig);
    if (!config.success) return { ok: false, kind: "permanent", code: "bad_sender_config" };
    const token = options.secret(config.data.accessTokenSecret);
    if (!token) return { ok: false, kind: "permanent", code: "missing_secret" };
    return {
      ok: true,
      token,
      url: `https://graph.facebook.com/${options.graphVersion}/${config.data.phoneNumberId}/messages`,
    };
  }

  async function post(prepared: { url: string; token: string }, body: unknown, timeoutMs: number) {
    return fetchImpl(prepared.url, {
      method: "POST",
      headers: { authorization: `Bearer ${prepared.token}`, "content-type": "application/json" },
      body: JSON.stringify(body),
      signal: AbortSignal.timeout(timeoutMs),
    });
  }

  return {
    supportsInteractive: true,
    freeFormWindowMs: DAY_MS,

    async send(message: OutboundText): Promise<SendOutcome> {
      const prepared = prepare(message.sender);
      if (!prepared.ok) return prepared;
      let response: Response;
      try {
        response = await post(prepared, sendBody(message), options.timeoutMs ?? DEFAULT_TIMEOUT_MS);
      } catch (error: unknown) {
        const timeout = error instanceof Error && (error.name === "TimeoutError" || error.name === "AbortError");
        return { ok: false, kind: "transient", code: timeout ? "timeout" : "network" };
      }
      let payload: unknown;
      try {
        payload = await response.json();
      } catch {
        payload = null;
      }
      if (!response.ok) return classifyError(response.status, payload);
      const parsed = ResponseSchema.safeParse(payload);
      if (!parsed.success) return { ok: false, kind: "transient", code: "invalid_response" };
      return { ok: true, providerMessageId: parsed.data.messages[0]?.id ?? "" };
    },

    async acknowledge(providerMessageId: string, sender: OutboundSender): Promise<void> {
      const prepared = prepare(sender);
      if (!prepared.ok) return;
      try {
        await post(prepared, acknowledgeBody(providerMessageId), ACK_TIMEOUT_MS);
      } catch {
        // Best effort (D121): a missing read receipt must never stop a conversation.
      }
    },
  };
}
```

```ts
/** D119: the window is checked before the call, so a doomed call is not wasted. */
async function windowClosed(
  deps: SendDeps,
  channel: ChannelAdapter,
  message: ClaimedMessage,
): Promise<boolean> {
  if (channel.freeFormWindowMs === null) return false;
  const state = await deps.db.contactChannelState.findUnique({
    where: {
      contactId_senderNumberId: { contactId: message.contactId, senderNumberId: message.senderNumberId },
    },
    select: { lastInboundAt: true },
  });
  const last = state?.lastInboundAt;
  return !last || deps.now().getTime() - last.getTime() > channel.freeFormWindowMs;
}

async function sendOnce(deps: SendDeps, message: ClaimedMessage): Promise<SendOutcome> {
  const { to, sender } = await targetOf(deps, message);

    });

    // An adapter that throws is a broken connection, not a verdict on the message.
    return { ok: false, kind: "transient", code: "channel_exception" };
```

```ts
import type { Logger } from "pino";
import { step } from "../engine/step";
import { findCampaignVersion } from "../store/campaigns";
import type { Database } from "../store/db";
import { inTransaction } from "../store/db";
import { findSessionById, markNeedsAttention } from "../store/sessions";
import { recordFlag } from "./apply-effects";
import { decodeState } from "./state-codec";

export interface FailureDeps {
  readonly db: Database;
  readonly logger: Logger;
  readonly now: () => Date;
}

/**
 * Spec §11.3, D120: after a definitive error — at send time or in a later delivery status — the
 * engine hears about it (`outbound_failed`), which flags the session. Only the flags are applied:
 * the reply that could not be delivered is the one that failed.
 */
export async function reportOutboundFailure(
  deps: FailureDeps,
  message: { readonly sessionId: string | null; readonly turnId: string | null },
): Promise<void> {
  if (message.sessionId === null) return;
  const sessionId = message.sessionId;
  await inTransaction(
    deps.db,
    async (tx) => {
      const session = await findSessionById(tx, sessionId);
      if (!session) return;
      const campaign = await findCampaignVersion(deps.db, session.campaignVersionId);
      if (!campaign) return;
      // The profile is not needed to run outbound_failed: the state is never saved here.
      const state = decodeState(session.engineState, {});
      const result = step(state, { type: "outbound_failed", at: deps.now().toISOString() }, campaign.definition);
      for (const effect of result.effects) {
        if (effect.type !== "FlagSession") continue;
        await recordFlag(tx, { sessionId, turnId: message.turnId, logger: deps.logger }, effect);
        if (effect.needsAttention) await markNeedsAttention(tx, sessionId);
      }
    },
    15_000,
  );
}
```

```ts
import type { Logger } from "pino";
import { parseWebhook, type ParsedMessage } from "../channels/meta-cloud/parse";
import { verifyChallenge, verifySignature } from "../channels/meta-cloud/signature";
import { handleStatusUpdate } from "../runtime/delivery";
import { receiveInbound } from "../runtime/receive";
import type { RuntimeConfig } from "../runtime/config";
import type { Database } from "../store/db";
import { insertDeadLetter } from "../store/dead-letters";
import type { PayloadRaw } from "../store/messages";
import type { JobQueue } from "../store/queue";
import { findSenderByPhoneNumberId } from "../store/senders";

export interface WebhookDeps {
  readonly db: Database;
  readonly queue: JobQueue;
  readonly config: Pick<RuntimeConfig, "debounceMs">;
  readonly logger: Logger;
  /** Meta's app secret: signs every POST. */
  readonly appSecret: string;
  /** The token chosen when the webhook was set up in Meta's console. */
  readonly verifyToken: string;
  readonly now: () => Date;
}

export interface HttpReply {
  readonly status: number;
  readonly body: string;
}

const OK: HttpReply = { status: 200, body: "ok" };
const MAX_RAW_TEXT = 10_000;

/** JSON that came from JSON.parse is already valid JSON: this only tells the type system. */
const asJson = (value: unknown): PayloadRaw => value as PayloadRaw;

/** GET: Meta checks the webhook once, when it is saved in the console. */
export function handleVerification(deps: WebhookDeps, query: URLSearchParams): HttpReply {
  const challenge = verifyChallenge(query, deps.verifyToken);
  return challenge === null ? { status: 403, body: "forbidden" } : { status: 200, body: challenge };
}

async function deadLetter(deps: WebhookDeps, raw: unknown, reason: string): Promise<void> {
  await insertDeadLetter(deps.db, { raw: asJson(raw), reason });
  deps.logger.warn({ reason }, "webhook item kept as a dead letter");
}

async function storeMessage(deps: WebhookDeps, message: ParsedMessage): Promise<void> {
  const sender = await findSenderByPhoneNumberId(deps.db, message.phoneNumberId);
  if (!sender) {
    await deadLetter(deps, message.raw, "unknown_sender");
    return;
  }
  await receiveInbound(
    { db: deps.db, queue: deps.queue, config: deps.config },
    {
      senderNumberId: sender.id,
      providerMessageId: message.providerMessageId,
      from: message.from,
      type: message.type,
      body: message.body,
      reply: message.reply,
      receivedAt: message.receivedAt,
      payloadRaw: asJson(message.raw),
    },
  );
}

/**
 * POST (D117): signature, parsing, storage and the turn's job, nothing slow. A failure of ours
 * (the database) throws: the server answers 500 and Meta tries again, which deduplication
 * makes safe. What is not ours to fix is kept as a dead letter and answered with 200.
 */
export async function handleWebhook(
  deps: WebhookDeps,
  rawBody: Buffer,
  signature: string | undefined,
): Promise<HttpReply> {
  if (!verifySignature(deps.appSecret, rawBody, signature)) {
    deps.logger.warn("webhook signature rejected");
    return { status: 401, body: "invalid signature" };
  }
  let json: unknown;
  try {
    json = JSON.parse(rawBody.toString("utf8"));
  } catch {
    await deadLetter(deps, { text: rawBody.toString("utf8").slice(0, MAX_RAW_TEXT) }, "invalid_json");
    return OK;
  }
  const parsed = parseWebhook(json);
  if (!parsed) {
    await deadLetter(deps, json, "not_whatsapp");
    return OK;
  }
  for (const item of parsed.rejected) await deadLetter(deps, item, "unreadable_item");
  for (const message of parsed.messages) await storeMessage(deps, message);
  for (const status of parsed.statuses) {
    await handleStatusUpdate(deps, {
      providerMessageId: status.providerMessageId,
      status: status.status,
      at: status.at,
      errorCode: status.errorCode,
    });
  }
  deps.logger.info(
    { messages: parsed.messages.length, statuses: parsed.statuses.length, ignored: parsed.ignored },
    "webhook handled",
  );
  return OK;
}
```

```ts
import { createServer, type IncomingMessage, type Server, type ServerResponse } from "node:http";
import { pingDatabase } from "../store/health";
import { handleVerification, handleWebhook, type HttpReply, type WebhookDeps } from "./webhook";

const WEBHOOK_PATH = "/webhooks/whatsapp";
/** A WhatsApp payload is a few KB; anything near this is not one. */
const MAX_BODY_BYTES = 1_000_000;

class BodyTooLarge extends Error {}

function readBody(req: IncomingMessage): Promise<Buffer> {
  return new Promise((resolve, reject) => {
    const chunks: Buffer[] = [];
    let size = 0;
    req.on("data", (chunk: Buffer) => {
      size += chunk.length;
      if (size > MAX_BODY_BYTES) {
        reject(new BodyTooLarge());
        req.destroy();
        return;
      }
      chunks.push(chunk);
    });
    req.on("end", () => {
      resolve(Buffer.concat(chunks));
    });
    req.on("error", reject);
  });
}

function send(res: ServerResponse, reply: HttpReply, contentType = "text/plain"): void {
  res.writeHead(reply.status, { "content-type": contentType });
  res.end(reply.body);
}

async function route(deps: WebhookDeps, req: IncomingMessage, res: ServerResponse): Promise<void> {
  const url = new URL(req.url ?? "/", "http://localhost");
  try {
    if (req.method === "GET" && url.pathname === "/health") {
      try {
        await pingDatabase(deps.db);
        send(res, { status: 200, body: JSON.stringify({ status: "ok" }) }, "application/json");
      } catch {
        send(res, { status: 503, body: JSON.stringify({ status: "database unavailable" }) }, "application/json");
      }
      return;
    }
    if (req.method === "GET" && url.pathname === WEBHOOK_PATH) {
      send(res, handleVerification(deps, url.searchParams));
      return;
    }
    if (req.method === "POST" && url.pathname === WEBHOOK_PATH) {
      const signature = req.headers["x-hub-signature-256"];
      send(
        res,
        await handleWebhook(deps, await readBody(req), typeof signature === "string" ? signature : undefined),
      );
      return;
    }
    send(res, { status: 404, body: "not found" });
  } catch (error: unknown) {
    if (error instanceof BodyTooLarge) {
      send(res, { status: 413, body: "payload too large" });
      return;
    }
    // Ours to fix and safe to retry: Meta will deliver the same message again.
    deps.logger.error({ error: error instanceof Error ? error.name : "unknown" }, "webhook failed");
    send(res, { status: 500, body: "error" });
  }
}

export function createWebhookServer(deps: WebhookDeps): Server {
  return createServer((req, res) => {
    void route(deps, req, res);
  });
}
```

```ts
import { z } from "zod";

// Meta versions its Graph API ("v23.0"). Check the current one in the app's dashboard when
// setting up: Meta retires old versions after about two years.
const GraphVersion = z.string().regex(/^v\d+\.\d+$/, 'like "v23.0"').default("v23.0");

const WebEnvSchema = z.object({
  META_APP_SECRET: z.string().min(1),
  META_VERIFY_TOKEN: z.string().min(1),
  META_GRAPH_VERSION: GraphVersion,
});

export interface WebConfig {
  readonly appSecret: string;
  readonly verifyToken: string;
  readonly graphVersion: string;
}

function messages(error: z.ZodError): string {
  return error.issues.map((issue) => `${issue.path.join(".")}: ${issue.message}`).join("; ");
}

const present = (source: Readonly<Record<string, string | undefined>>) =>
  Object.fromEntries(Object.entries(source).filter(([, v]) => v !== undefined && v.trim() !== ""));

/** The web process needs the secrets that authenticate Meta's calls (no values in the errors). */
export function parseWebConfig(source: Readonly<Record<string, string | undefined>>): WebConfig {
  const result = WebEnvSchema.safeParse(present(source));
  if (!result.success) throw new Error(`Invalid web configuration: ${messages(result.error)}`);
  const env = result.data;
  return { appSecret: env.META_APP_SECRET, verifyToken: env.META_VERIFY_TOKEN, graphVersion: env.META_GRAPH_VERSION };
}

/** The worker only sends: it needs the version, and the tokens it reads by the numbers' secret names. */
export function parseGraphVersion(source: Readonly<Record<string, string | undefined>>): string {
  const result = z.object({ META_GRAPH_VERSION: GraphVersion }).safeParse(present(source));
  if (!result.success) throw new Error(`Invalid configuration: ${messages(result.error)}`);
  return result.data.META_GRAPH_VERSION;
}
```

```ts
export function registerWebCommands(program: Command, deps: CliDeps): void {

    .command("start")
```
